# 💌 Letter Diary — สมุดจดหมายของฉัน

โปรแกรมเขียนและเก็บจดหมายบน Windows มีอิโมจิ โหมดมืด และเพลง lofi เบา ๆ

## ดาวน์โหลด

👉 **[ไปหน้าดาวน์โหลด (Releases)](../../releases/latest)** แล้วกดไฟล์ **Install-Letter-Diary-x.x.x.exe**

## วิธีติดตั้ง

1. ดาวน์โหลดไฟล์ **Install-Letter-Diary-x.x.x.exe** (ตัวเลขคือเวอร์ชัน)
2. ดับเบิลคลิกไฟล์ที่โหลดมา (ปกติอยู่ในโฟลเดอร์ Downloads)
3. ถ้า Windows ขึ้นหน้าจอสีน้ำเงินว่า **"Windows protected your PC"** ให้กด **More info** แล้วกด **Run anyway**
   (ขึ้นเพราะเป็นโปรแกรมของนักพัฒนาอิสระ ยังไม่มีลายเซ็นดิจิทัล ไม่ได้แปลว่าอันตราย)
4. จะมีหน้าต่างติดตั้งขึ้นมาให้เลือก **โฟลเดอร์ที่จะติดตั้ง** (ค่าเริ่มต้นใช้ได้เลย หรือจะเปลี่ยนที่เก็บเองก็ได้) แล้วกด **Install**
5. ติดตั้งเสร็จโปรแกรมจะเปิดขึ้นมาให้อัตโนมัติ

## เปิดโปรแกรมครั้งต่อไป

- ดับเบิลคลิกไอคอน **Letter Diary** บนหน้า Desktop
- หรือกดปุ่ม Start แล้วพิมพ์ **Letter Diary**

## การใช้งานเบื้องต้น

- **✍️ เขียนฉบับใหม่** เริ่มเขียนจดหมาย
- **😊 อิโมจิ** เลือกอิโมจิใส่ในจดหมาย
- **🌙** สลับโหมดมืด/สว่าง · **🎵** เปิด/ปิดเพลง และปรับเสียง
- **🖼️ บันทึกเป็นรูป** ส่งจดหมายออกเป็นรูปภาพ
- **📦 สำรองข้อมูล / 📥 นำเข้า** สำรองและกู้คืนจดหมายทั้งหมด
- จดหมายบันทึกให้อัตโนมัติ

## การอัปเดต

โปรแกรมตรวจหาเวอร์ชันใหม่เองทุกครั้งที่เปิด เมื่อพบจะขึ้นแถบแจ้งด้านบน กด **รีสตาร์ทเพื่ออัปเดต** ได้เลย จดหมายที่เขียนไว้ไม่หาย
หรือกดปุ่ม **🔄 ตรวจอัปเดต** มุมซ้ายล่างเพื่อตรวจเอง

## ถอนการติดตั้ง

เลือกวิธีใดก็ได้:

- กด Start → พิมพ์ **Letter Diary** → จะเจอโฟลเดอร์โปรแกรม เปิดแล้วกด **Uninstall Letter Diary**
- หรือไปที่ Settings → Apps → Installed apps → ค้นหา **Letter Diary** → กด **Uninstall**

ข้อมูลจดหมายที่เขียนไว้เก็บแยกจากตัวโปรแกรม ถอนการติดตั้งแล้วจดหมายจะไม่หายไปด้วย (ถ้าติดตั้งใหม่อีกครั้งจะเจอจดหมายเดิม)
